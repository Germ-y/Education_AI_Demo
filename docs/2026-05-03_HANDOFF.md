## 학생 스테이지 UI

- iframe 미리보기와 실제 학생 메인 화면에서 스케일/비율이 달라 보이던 문제를 줄였다.
- 카드 매칭과 순서 배열에서 보드가 잘리거나 다음 버튼이 구조형 화면에서 사라지는 문제를 정리했다.
- 완료 피드백은 레이아웃을 밀어내지 않는 토스트처럼 띄우도록 했다.
- 기본 오디오 재생 바는 사진 영역을 너무 많이 차지해서 숨기고, 둥근 재생 버튼만 노출했다.
- 카드 트레이는 최대 3개 선택지를 기준으로 공백을 줄이고, 선택 카드가 올라가는 동작이 보이도록 간격을 재배치했다.

협업자가 볼 파일:

- `frontend/app/student/stage/StudentStageExperience.tsx`

주의:

- “조부모님” 같은 카드 문구는 프론트에서 DB에 새로 넣은 값이 아니라 현재 콘텐츠 데이터에서 렌더링된 값이다.
- 오디오는 제거한 것이 아니라 숨겨진 `audio` 요소를 버튼으로 제어한다. 접근성 때문에 버튼 `aria-label`은 유지한다.
- 구조형 화면은 선택지 개수에 따라 공백과 잘림이 다시 생기기 쉬우니, 새 템플릿을 붙일 때 실제 학생 화면과 교사 iframe 미리보기를 같이 봐야 한다.

남은 확인:

- 1366x768, 1536x864, iframe 미리보기 981x736 기준으로 카드 매칭/순서 배열/빈칸 화면을 다시 비교한다.
- 완료 토스트가 다음 버튼이나 카드 트레이를 가리지 않는지 stage 2/3 모두 확인한다.
- 재생 버튼 클릭 후 재생/일시정지 상태 표시가 기대대로 바뀌는지 확인한다.

## 생성 로그

- 기본 로그 파일: `backend/logs/generation.log`
- 설정 키: `GENERATION_LOG_FILE`
- 로테이션: 1MB, 백업 5개
- 로그 대상:
  - `app.api.routes.ai`
  - `app.api.routes.contents`
  - `app.ai.openai_provider`
  - `app.ai.elevenlabs_provider`

예시:

```text
[04:12:03] INFO contents.assets.package_started content_id=content_fraction_001 student_id=student_learning_fraction asset_count=10
[04:12:03] INFO contents.assets.generating content_id=content_fraction_001 progress=1/10 asset_id=... type=image role=...
[04:12:16] INFO openai.image.returned model=gpt-image-2 output_path=... elapsed_sec=12.4
```

남은 확인:

- provider key가 있는 환경에서 `POST /api/contents/{contentId}/assets/generate-package`를 실제로 돌려 `progress=1/10`부터 마지막 asset까지 파일에 남는지 본다.
- 로그는 운영 디버깅용 파일 로그다. 느려지는 수준의 동기 작업은 아니지만, 대량 생성 시 로그 로테이션만 확인하면 된다.
