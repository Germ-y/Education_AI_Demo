# Docs

문서는 요청/인수인계 속도를 위해 최소 문서만 유지한다.

- [HANDOFF.md](HANDOFF.md): 현재 작동 흐름, 실행, 검증, 인수인계 요약
- [ISSUES.md](ISSUES.md): 남은 이슈, 병목, 우선순위, 다음 커밋 순서
- [API.md](API.md): 최신 REST API 요약
- [../backend/data/README.md](../backend/data/README.md): 데모 DB dump/seed 복원 방법

이전 세부 설계 문서는 코드와 최신 인수인계 문서가 대신한다. API나 DB가 바뀌면 `HANDOFF.md`, `ISSUES.md`, `API.md`, `backend/data/README.md` 중 필요한 곳만 갱신한다.
